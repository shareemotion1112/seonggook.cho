결제 · 관리자 · 파일 업로드 구현 역량

💳 1. 결제 연동 경험 (해외카드 & 예약금 결제)

실무 경험 및 적용 방안

  • 토스페이먼츠 실결제 연동 경험: 마이마블(mymarble.kr)에서 토스페이먼츠(TossPayments)를 직접 연동하며 가맹점 심사 대응, 결제 승인 API 호출, 결제 유효성 검증, 실패 시 롤백 및 결제 내역 DB 기록, 웹훅 처리를 완벽히 구현했습니다.
  • 해외카드 결제 적용 방안: PG 결제 연동의 전체적인 동작 구조(결제창 호출 → 서버 승인 검증 → 웹훅 처리)를 직접 구축해 보았으므로, 이번 프로젝트에서 선정할 해외카드 결제(토스페이먼츠 해외카드 또는 Stripe 등) 역시 공식 문서를 준수하여 예약금 결제 및 웹훅 입금 확인 로직을 안정적으로 구현하겠습니다.

🛠️ 2. 관리자 기능 구현 (Admin Dashboard)

실무 경험 및 적용 방안

  • 단일 통합 관리자 페이지 구축: 신청 목록 조회, 검색 및 필터링(대기/승인/반려/결제완료), 예약 상세 뷰를 직관적인 반응형 관리자 화면으로 구현합니다.
  • 상태 변경 및 내부 메모: 관리자가 고객의 신청 상태를 클릭 한 번으로 변경하고, 내부 검토용 비공개 메모를 작성·저장할 수 있는 API 및 UI를 구성합니다.
  • 이메일 자동 안내 연동: 관리자가 상태를 '승인'으로 변경하면, 고객 이메일로 검토 완료 안내 및 해외카드 예약금 결제 링크가 자동 발송되도록 Nodemailer / Resend API 트리거를 구축합니다.

📁 3. 파일(이미지/영상) 업로드 구현

실무 경험 및 적용 방안

  • 안정적인 파일 업로드 파이프라인: 사용자가 조건부 예약 시 제출하는 본인 확인 및 상담용 이미지/영상을 클라우드 스토리지(S3 또는 Firebase/Supabase Storage)에 Presigned URL 방식으로 안전하고 빠르게 업로드합니다.
  • 보안 및 유효성 검증: 허용된 확장자(JPG, PNG, MP4 등)와 용량 제한을 프론트엔드와 백엔드 양단에서 이중 검증하고, 관리자 화면에서만 열람 가능한 서명된 안전한 URL을 제공합니다.

[2주차 | 6~10일차] 조건부 예약 신청 폼 & 관리자 기능 구축

의료기관·상품·옵션·희망일 선택 및 신청자 정보 입력 폼. 이미지/영상 파일 업로드 연동. 관리자 전용 신청 목록·상세 뷰, 상태 변경(대기/승인/반려), 내부 메모 기능 완성 및 1차 시연.

[3주차 | 11~15일차] 이메일 상태 안내 & 해외카드 예약금 결제 연동

관리자 상태 변경에 따른 고객 이메일 자동 발송 트리거 연동. 승인 고객용 해외카드(Stripe 등) 예약금 결제 페이지 및 웹훅 연동, 결제 완료 후 예약 확정 처리.

[4주차 | 16~20일차] 실데이터 통합 테스트, 운영 배포 & 인수인계

전체 플로우(신청 → 검토 → 이메일 수신 → 결제 → 확정) End-to-End 검증, 예외 처리 및 중대 오류 해소. 운영 서버 배포 완료, 소스코드·계정 정보 및 관리자 운영 매뉴얼 문서 인계.
